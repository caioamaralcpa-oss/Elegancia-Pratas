# Avaliação preliminar de impacto à privacidade

Documento de trabalho para revisão jurídica. A loja ainda não processa pedidos reais pelo código atual.

Dados esperados: identificação e contato de clientes, endereço de entrega, pedidos e status. Possível CPF apenas para fins fiscais/antifraude após confirmação de necessidade. Não coletar dados de cartão; usar checkout hospedado.
